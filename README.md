# aegis-foundry-gaming-store

An enterprise-grade e-commerce web application for high-performance PC hardware, custom gaming rigs, and pro-tier peripherals. Features real-time inventory management, custom rig configurators, telemetry logistics tracking, and responsive full-stack architecture.

## Architecture Overview

- **Primary Language:** TypeScript
- **Core Engine:** Built on Nexus-Enterprise v3.0 modular runtime.

## Getting Started

```bash
npm install
npm run dev
```
